# 📺 电视盒子PK

电视盒子性能对比工具 · 数据来源于B站数码区UP主

**在线访问**：[https://drchjiang.github.io/tvboxpk/](https://drchjiang.github.io/tvboxpk/)

---

## 📋 这是什么

一个电视盒子参数对比页面，汇总了市面上主流电视盒子（小米、腾讯极光、当贝、雷鸟等）的硬件配置和影音支持情况，方便快速对比、筛选、排序，找到最适合自己的设备。

---

## ✨ 功能列表

- 查看完整参数：总分、制程、CPU、GPU、内存带宽、系统跑分、WiFi、USB 等 16 项配置
- 搜索型号：输入名称实时过滤，快速定位目标设备
- 按芯片筛选：一键筛选「晶晨」或「全志」芯片的设备
- 按指标排序：点击表头按总分、CPU、GPU、制程、内存带宽等升序/降序排列
- 影音支持对比：4K60Hz、HDR10、杜比视界、杜比全景声、DTS:X 等 8 项规格
- 性能图表：总分、CPU、GPU 三围柱状图（原生 SVG 实现，无第三方图表库），直观对比
- 点击查看详情：点击任意型号（电视端还支持遥控器焦点 + 确认键），弹出完整参数和影音支持详情
- 深色/浅色模式：一键切换，护眼舒适，同步安卓浏览器地址栏颜色
- 🔒 隐私保护：零第三方请求（无 Google Fonts、无 CDN 图表库）、无统计脚本、无 Cookie，主题偏好仅存于本地浏览器
- 📱 安卓适配：刘海屏/手势条安全区避让、dvh 视口高度、触控目标加大、表格横滑提示、系统字体渲染、TV 遥控器焦点支持

## 🔒 隐私说明

本页面为纯静态页面：

- 不收集任何数据，无统计/追踪脚本，无 Cookie
- 零第三方资源请求（字体、图表均为本地/系统实现），页面可完全离线使用
- 已禁用 Referrer 泄露，跳转外部链接时不会携带本页地址；所有外链均带 `noopener noreferrer`
