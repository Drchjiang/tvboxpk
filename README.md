## 📋 这是什么

一个电视盒子参数对比页面，汇总了市面上主流电视盒子（小米、腾讯极光、当贝、雷鸟等）的硬件配置和影音支持情况，方便快速对比、筛选、排序，找到最适合自己的设备。

---

## ✨ 功能列表

- 查看完整参数：总分、制程、CPU、GPU、内存带宽、系统跑分、WiFi、USB 等 16 项配置
- 搜索型号：输入名称实时过滤，快速定位目标设备
- 按芯片筛选：一键筛选「晶晨」或「全志」芯片的设备
- 按指标排序：点击表头按总分、CPU、GPU、制程、内存带宽等升序/降序排列
- 影音支持对比：4K60Hz、HDR10、杜比视界、杜比全景声、DTS:X 等 8 项规格
- 性能图表：总分、CPU、GPU 三围柱状图，直观对比
- 点击查看详情：点击任意型号，弹出完整参数和影音支持详情
- 深色/浅色模式：一键切换，护眼舒适
