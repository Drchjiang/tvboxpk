买盒子别只比总分，这六项才决定每天用起来顺不顺。
1解码能力
是什么把压缩过的视频「还原」成画面的本领，页面下方编解码表列的就是它认得哪些格式。
为什么重要格式不认得就只能靠软件硬撑，容易卡顿、发烫、音画不同步，4K 片源最明显。
PK 看什么编解码表里 ✔ 越多越省心；4K 片源看 H.265，网络视频再看 AV1；HDR 位深看本表，杜比视界看下面影音支持表。
2GPU 能力
是什么负责画面绘制的部分，桌面滑动、海报墙、动画和小游戏都靠它。
为什么重要GPU 弱，CPU 再强也会觉得「点一下等半天」，界面不跟手。
PK 看什么看 GPU 那一列，别只盯总分；它和 CPU 是两件事，别混着比。
3CPU 单核能力
是什么处理器单个核心干活的速度。多数应用一次只用一个核。
为什么重要打开应用、加载封面、切换设置这些「一下一下」的操作，靠单核，不靠核心数量。
PK 看什么看 CPU 一列，别被「4 核 / 5 核」带偏；总分接近时，单核高的日常更跟手。
4内存与存储
是什么内存决定能同时开多少应用，存储决定能装多少应用和缓存，表里「2+32」「4+64」就是它。
为什么重要内存小，切个应用就重新加载；存储小，装几个播放器就满。
PK 看什么同价位优先选大的；只写「支持 4K」不够，高码率片源很吃内存和缓存。
5Wi-Fi 与网口
是什么片源进盒子的通道，双频 / WiFi6、百兆 / 千兆网口说的都是它。
为什么重要高码率 4K 原盘、家里 NAS 播放，卡在缓冲上时换什么芯片都没用。
PK 看什么插网线看「网口」是不是千兆；只用无线看 WiFi 是不是双频 / WiFi6。
6系统与安卓版本
是什么盒子的系统版本和自带桌面，表里「安卓版本」一列就是它。
为什么重要版本太老，新应用装不上、投屏和会员认证容易出问题；自带桌面还决定开机广告和能不能换桌面。
PK 看什么别只比版本数字，也留意是否还在更新、能不能装第三方播放器和桌面。
先想清楚自己看什么片源、怎么连网，再回表里找对应的列，比挑总分最高的更靠谱。
